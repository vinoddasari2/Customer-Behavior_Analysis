# Customer Shopping Behavior Analysis

## 📌 Project Overview

This project analyzes **3,900+ customer transaction records** to understand customer purchasing behavior, identify purchasing trends, analyze customer segments, and generate actionable business insights.

The project follows an end-to-end data analytics workflow using **Python, SQL, and Power BI**, starting from data preparation and exploratory analysis to business analysis and interactive dashboard development.

---

## 🎯 Objectives

The main objectives of this project are to:

* Understand customer purchasing patterns.
* Identify different customer segments.
* Analyze revenue and product performance.
* Study customer subscription behavior.
* Evaluate the effectiveness of discounts.
* Identify important business trends and insights.
* Create an interactive dashboard for monitoring key business KPIs.
